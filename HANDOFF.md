## Goal
A mobile chess clock as a web app: the screen is split in two halves, the top half rotated 180° so each player reads their own time from their side of the board.

## How it works (for agents)
- Static site, no build step: `index.html`, `css/style.css`, ES modules in `js/` (`clock.js` is pure logic and unit-tested), `sw.js` service worker (network first, cache fallback), `manifest.webmanifest`, icons in `icons/` (PNGs generated by `scripts/make-icons.mjs`).
- `npm test` runs the unit tests. New app files must be added to `ASSETS` in `sw.js` (a test checks this).
- Stored in localStorage: settings, current game, history (max 50 games).

## Legal notes
- Saving settings, the ongoing game and the game history in the browser's local storage is functional storage the user asks for and normally needs no consent (Swedish Electronic Communications Act ch. 9 s. 28). No personal data is collected and nothing leaves the device. Re-check if analytics or third-party services are ever added.
- System fonts and sounds generated in the browser (Web Audio) – no licensed assets. Spoken warnings use the device's built-in speech.
